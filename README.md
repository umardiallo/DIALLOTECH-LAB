# DIALLOTECH LAB
### Infrastructure réseau, systèmes et sécurité

**Auteur : Chaikou Oumar Diallo**  
**Statut : laboratoire en cours de réalisation**

## Présentation

DIALLOTECH LAB est mon laboratoire informatique personnel.
Il reproduit progressivement une infrastructure d’entreprise
pour développer mes compétences en administration systèmes,
réseaux et sécurité.

Ce portfolio documente les configurations réalisées,
les tests de fonctionnement et les problèmes résolus.

## Objectifs du projet

- Construire une infrastructure virtualisée avec VMware Workstation.
- Segmenter les réseaux et contrôler les communications avec OPNsense.
- Administrer le domaine diallotech.lab avec Active Directory.
- Configurer les services DNS et DHCP.
- Intégrer des postes Windows 11 au domaine.
- Organiser les utilisateurs, les groupes et les permissions.
- Appliquer des stratégies de groupe.
- Ajouter progressivement la supervision et la sécurité.

## Technologies du laboratoire

VMware Workstation · OPNsense · Windows Server · Windows 11
Active Directory · DNS · DHCP · GPO

Évolutions prévues : Ubuntu, Zabbix et Wazuh.
